Case Study

식자재

엠즈푸드 냉장/냉동 물류

Challenge

온도별 존 구분 운영, WMS 연동 유통기한 자동 관리, 전국 HUB 네트워크 구축

Result

✓ 물류비 15% 절감   ✓ 오배송률 0.01% 달성   ✓ 신선도 클레임 80% 감소

유통/이커머스

G마켓 동탄 허브센터

Challenge

급증하는 온라인 주문 대응, 당일 출고 비율 향상 필요

Solution

DPS/DAS 자동화 설비 도입, 피킹 동선 최적화, 실시간 재고 가시화

Result

✓ 생산성 30% 향상   ✓ 당일출고율 99%   ✓ 인력 효율화 20%

의류/패션

라코스테 어패럴 센터

Challenge

시즌별 물량 변동 대응, 의류 특성에 맞는 보관/관리 필요

Solution

행거 보관 시스템 구축, 시즌별 유연한 공간 운영, 반품 검수 프로세스 표준화

Result

✓ 반품처리 TAT 50% 단축   ✓ 재고정확도 99.9%   ✓ 상품 손상률 0.1%
